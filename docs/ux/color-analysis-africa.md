# Colour analysis

## 1. Why collaboration SaaS rarely use green (it is not a taboo)
| Reason | Reality | Mitigation |
|---|---|---|
| **Semantic clash with "success"** | Main design argument (UX StackExchange, UX Atlas, Contentful "stoplight conflict"). The conflict is about *shade proximity*, not hue family; Gojek (#00AA13) runs a green brand + distinct success green in its Asphalt DS. | Brand malachite is **blue-green & dark**; success uses a **separate yellower green** (#3F7A1C light / #86C66B dark) + always an icon. Semantic tokens point to different primitives per theme. |
| Category conventions | Collaboration tools went yellow (Miro), violet (Boardmix, Cynoia), blue (AFFiNE), navy/orange (Collaboard). Green = fintech/eco/health in the West. | This is exactly why green differentiates in *our* category. |
| Red-green colour blindness | Affects status signals, not a brand accent. | Never colour-only; test greyscale. |

**In Africa specifically** green is *common*, not rare — but in other categories:
- Telco/fintech: Safaricom & M-Pesa "kiosk green" (Kenya, iconic), Flutterwave secondary #009A46, Paystack secondary green; MTN owns yellow, Orange owns orange, Wave blue.
- **National flags & politics**: green appears in ~half of African flags (Nigeria #008751, Senegal #00853F, Ghana, Kenya, Ethiopia, Cameroon…) and in the pan-African red-gold-green. Bright flag-green could read as *one country's* colour or a party colour — a risk for a pan-African, government-facing product.
- Meaning: across sources green = growth, fertility, abundance, land (positive); sacred/positive association with Islam in the Sahel & North Africa.

→ Verdict: green is **viable and positive**, provided it is **not flag-green, not M-Pesa-green**: deep, blue-leaning, mineral. Our malachite #0B5D49 (hue ≈ 165°) is far from flag greens (hue ≈ 145–150°, high saturation) and fintech greens.

## 2. Colour meanings in Africa (pan-regional patterns — Africa is not a monolith)
| Colour | Recurrent meanings (sources below) | Brand risk |
|---|---|---|
| **Gold / yellow** | wealth, royalty, status, fertility (kente gold) | MTN yellow owns bright yellow; gold as metal ornament = premium ✔ |
| **Black** | maturity, wisdom, power, ancestors (kente, adinkra); elegance | ✔ luxury base |
| **White** | purity, peace, spirituality (also mourning in some contexts) | ✔ paper base |
| **Green** | growth, land, abundance; Islam (Sahel/North) | flag/party/fintech proximity → use deep mineral shade |
| **Blue / indigo** | harmony, protection, sky/water; indigo = adire (Yoruba), Tuareg, Sahel dyeing traditions; North-African blue | SaaS-saturated in bright blue; **deep indigo** is distinctive and luxurious |
| **Red** | life, blood, power, sacrifice; mourning (South Africa context) | ✘ conflicts with error state; avoid as brand |
| **Purple** | royalty, wealth | ✘ taken by Boardmix/Cynoia |
| Ochre / terracotta | earth, pigments | ✘ "AI cliché" (cream + serif + terracotta) and Flutterwave orange |

## 3. Two directions to compare in Penpot (A1 step)
| | **A — Malachite** (current) | **B — Indigo Adire** |
|---|---|---|
| Story | Congolese copper-belt mineral; precious, calm | Yoruba adire & Sahel indigo dyeing; depth, craft, protection |
| Accent | #0B5D49 (7.5:1 on paper) · dark #3FBF95 | #26306B (11.7:1) · hover #34408A · dark #8E9BEA (7.4:1) |
| Ornament | gold #B08A2E | gold #B08A2E (indigo + gold = strong luxury pairing) |
| Success token | #3F7A1C / dark #86C66B (distinct from brand) | malachite family free for success |
| Differentiation | only deep green in category | deep indigo vs bright blues of AFFiNE / Cynoia navy — differentiable but closer |
| Gov / pan-African fit | positive; avoid flag-green (done) | neutral, no flag/party associations |
| Risk | perceived as fintech by some | perceived as "corporate blue" if not deep enough |

Recommendation: produce both A and B foundations + 3 key screens (Home, Board, Pricing) in Penpot, then test with 5–8 target users across 3 countries (S1 + S2). Decide on evidence.
