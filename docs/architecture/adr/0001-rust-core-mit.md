# ADR-0001 — Cœur en Rust, licence MIT

> **Amendé le 2026-11-11 par [ADR-0016](0016-dual-licence-mit-apache.md)** : la licence est désormais **MIT OR Apache-2.0** (double licence au choix). Le reste de l'ADR (cœur Rust, clean-room) est inchangé.

- Statut : accepté
- Date : 2026-11-10
- Décideur : Jean Balin

## Décision
Le cœur du produit est écrit en Rust ; le dépôt est publié sous licence MIT ; démarche clean-room.

## Conséquences
Choix du framework UI (Tauri, GPUI, Dioxus…) et du moteur CRDT à trancher dans des ADR dédiés.
