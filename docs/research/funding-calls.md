## Recommandation
1. **NLnet Restack avant le 3 janvier 2027** : le meilleur fit, rien ne bloque (pas d'entité, pas d'equity). Périmètre suggéré : brique open source réutilisable (sync Loro local-first + auto-hébergement), 30–50 k€.
2. Trancher **ADR-0009 (entité)** : elle conditionne Bourse French Tech (FR), Fuzé (cofondateur africain) et DER/FJ (SN).
3. Après l'alpha + 3 partenaires de conception : Fuzé (si cofondateur) puis DER/FJ Catalyst.
4. Mettre une alerte sur paens.sn / mctn.sn / PRODAP.
