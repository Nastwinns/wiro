# 14 — Marketing site (apps/landing) — inspired by Boardmix structure, clean-room, Malachite identity

Frames: 1440 desktop, 390 mobile. Tone: calm luxury; lots of white; product screenshots as hero material; Fraunces display, Inter body.

## S-14.1 Home
1. Nav: logo · Produit · Cas d'usage · Souverain · Tarifs · Open source (GitHub stars) · Se connecter · **Commencer gratuitement**.
2. Hero: Fraunces 64 "Écrivez, dessinez, décidez — ensemble." sub: docs + tableau blanc, open source, hors ligne, hébergé chez vous. CTA primary + "Voir la démo (2 min)". Live interactive mini-canvas (lightweight) instead of image.
3. Logos / social proof (real only; none until first customers — no fake logos).
4. Use-case tabs: Ateliers · Spécifications · Planification · Wiki — each with short loop video/screens.
5. "Conçu pour l'Afrique": hors ligne, faible débit (data meter), FR/EN + langues locales, prix en monnaie locale.
6. Souveraineté: déploiement sur vos serveurs / cloud national, air-gapped, audit, code ouvert MIT → CTA "Parler à un partenaire".
7. Performance proof: "10 000 objets à 60 i/s sur un portable d'entrée de gamme" (benchmark link).
8. Open source block: GitHub stars, contributors map, licence MIT.
9. Testimonials (only real), FAQ, final CTA, footer (partners, docs, status, security, legal, language switch).

## S-14.2 Pricing
Tiers from market study (Community, Personal Cloud, Team, Business, Sovereign, Services); currency switch (XOF / NGN / KES / EUR / USD) with round local prices; "Qui est facturé ?" block; FAQ (guests free, no auto-upgrade, quarterly billing).

## S-14.3 Sovereign / Government
Deployment models diagram, compliance (data residency per country policy), security (SBOM, signed releases), tender pack download, partner directory, case studies.

## S-14.4 Download
Auto-detect OS (Windows/macOS), checksums & signatures, self-host instructions (compose, Helm, air-gapped).

## S-14.5 Partners
Programme tiers, benefits, apply form, partner directory by country.

## S-14.6 Docs/Blog shell
Docs (self-host, admin, API), changelog, blog (demo posts for X).
