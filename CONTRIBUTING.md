# Contributing

Thanks for your interest!

1. Read [AGENTS.md](AGENTS.md) — the **clean-room** and **licence** rules apply to humans and AI agents alike.
2. Open an issue before large changes; small fixes can go straight to a PR.
3. Use Conventional Commits (`feat:`, `fix:`, `docs:` …). One logical change per PR; CI must be green.
4. **Sign off your commits (DCO)**: `git commit -s` — certifies you wrote the code or have the right to submit it under MIT (https://developercertificate.org).
5. Never paste code, assets or text from projects whose licence is not MIT-compatible (e.g. tldraw SDK, proprietary tools).
6. Translations: we use Fluent (`.ftl`) files in `locales/`. Swahili is the first community locale after FR/EN.

Code of conduct: we follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Report issues to the maintainers privately.
