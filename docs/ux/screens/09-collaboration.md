# 09 — Collaboration

## S-09.1 Share dialog (520 px)
- Invite field (emails, groups) + role select (Éditeur, Commentateur, Lecteur) + "Inviter".
- People with access list (inherited from space shown with "via Espace X").
- **Lien d'invité**: toggle on/off, role (édition/commentaire/lecture), expiry (1 j, 7 j, 30 j, jamais), password optional, "Copier le lien", **QR code** (for workshops in a room).
- Workspace/space visibility; "Publier sur le web" (off by default; disabled in sovereign if policy).
- Footer: "Copier le lien" · learn more. Billing transparency note: "Les invités et lecteurs ne sont jamais facturés."

## S-09.2 Comments
Right panel threads list (open/resolved filter); inline: highlight in doc, pin on canvas; composer with @mention, attachments, emoji; resolve, reopen, link to thread.

## S-09.3 Presence
Avatars in topbar (click = follow), coloured cursors with name labels on canvas, selection outlines in user colour, "typing" in docs as caret flag. Low-bandwidth: cursors throttled (4 Hz).

## S-09.4 Version history
Right panel timeline grouped by day/session with authors; named versions; preview (read-only overlay); restore whole page or copy a block/frame; diff highlight for docs.

## S-09.5 Export / import dialog
Export: scope (page, page + children, space, workspace), format (Markdown+assets, JSON open format, PDF, PNG/SVG for boards), options (include comments, history); progress; offline-capable.
