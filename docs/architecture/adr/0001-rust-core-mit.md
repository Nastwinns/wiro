# ADR-0001 — Cœur en Rust, licence MIT

- Statut : accepté
- Date : 2026-11-10
- Décideur : Jean Balin

## Décision
Le cœur du produit est écrit en Rust ; le dépôt est publié sous licence MIT ; démarche clean-room.

## Conséquences
Choix du framework UI (Tauri, GPUI, Dioxus…) et du moteur CRDT à trancher dans des ADR dédiés.
