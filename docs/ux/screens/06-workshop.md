# 06 — Workshop / facilitation (UC1)

Available on every tier. Facilitator = page editor who starts a session.

## S-06.1 Workshop bar
Top-centre pill when session active: session name · participants count · timer · vote status · private mode badge · "Suivre" · "Terminer". Participants see a reduced version (timer + vote budget + follow state).

## S-06.2 Timer
Presets 1/3/5/10/15 min + custom; start/pause/add 1 min; optional soft chime; visible to all, also in tab title. End → toast + optional lock editing.

## S-06.3 Voting
Setup dialog: what can be voted (stickies in frame X / all), votes per person (default 3), multiple votes on same item (y/n), anonymous (y/n), duration. During: dot badge on items, remaining budget in bar. Results: ranked list panel, "Trier par votes" (rearranges into column in a new frame), export to doc.

## S-06.4 Private mode
Participants' new stickies hidden from others (blurred card with author colour) until facilitator clicks "Révéler". Indicator for everyone: "Mode privé — vos idées sont visibles par vous seul".

## S-06.5 Follow / summon / raise hand / reactions
"Me suivre" forces viewports to follow facilitator (participants can break away with a visible "Revenir"); "Rassembler" teleports everyone to facilitator view; raise-hand queue; emoji reactions floating 2 s (throttled in low-bandwidth mode).

## S-06.6 Workshop templates gallery
Cards: Rétro 4L, Start/Stop/Continue, Brainstorm, SWOT, Impact/Effort, Parcours utilisateur, Lean canvas, Atelier de priorisation, Comité de pilotage. Each: preview, duration, steps, facilitator guide (doc side-by-side).

Acceptance: 30 participants incl. 10 guests on 3G, timer drift < 1 s, votes consistent after reconnect.
