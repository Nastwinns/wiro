# 08 — Knowledge base & search (UC4)

## S-08.1 Wiki page
Doc page variant: cover + Fraunces title, "Vérifiée" badge (owner, expiry date → reminder), table of contents right, "Pages liées", last reviewed. Space home = wiki index with sections and pinned pages.

## S-08.2 Backlinks & graph
Right panel: incoming links with context snippet, unlinked mentions ("Lier"). Optional graph view (canvas-rendered) per space.

## S-08.3 Search
Full page or palette-expanded: query field, filters (space, type doc/board/database, author, date, has comments), results grouped: Pages · Contenu des tableaux (sticky/text matches with board thumbnail and jump-to-object) · Bases de données · Commentaires. Highlights; keyboard nav. Offline: local index, badge "Résultats locaux".

## S-08.4 Templates gallery
Categories: Ateliers · Produit · Planification · Wiki · Gouvernance publique (comité, plan d'action, note ministérielle) · Personnels. Preview pane, "Utiliser", workspace templates (admins can publish). Template = page with placeholders.

## S-08.5 Trash
List with type, original location, deleted by/when, restore / delete forever (confirm). Retention policy shown ("Supprimé définitivement après 30 jours").
