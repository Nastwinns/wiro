# Règles
- Page cible : **B14 · Prototype flows**. Copies par `tools/penpot/proto_copy.js` (préfixe `P · `, ex. `P · S-03.1 Home / 1440 / Light / Default`). Une frame n'est copiée **qu'une fois** (propriétaire = le flow où elle apparaît en premier) ; les autres flows la ciblent. Si une cible appartient à un autre flow et n'existe pas encore, attendre (réessayer 5 min) puis la signaler : ne jamais la créer.
- Disposition : flow *n* (F1 = 0) sur la ligne `y = n × 1500` ; frames principales à `x = i × 1600` (y = ligne) ; overlays à `y = ligne + 1000`, `x = j × 600`. Le point d'entrée (flow Penpot) est la première frame.
- Interactions (API `shape.addInteraction(trigger, action)`) : `click` + `navigate-to` entre frames complets ; `open-overlay` (menus, popovers, dialogues, toasts) avec `closeWhenClickOutside: true` et, pour les dialogues, `addBackgroundOverlay: true` ; `close-overlay` / `previous-screen` pour Annuler/Fermer/Retour. Le déclencheur est le **calque** (bouton, ligne, onglet) dont le texte ou le nom correspond ; l'interaction se pose sur le board parent du texte (bouton), pas sur le texte. Si aucun déclencheur plausible n'existe dans la frame, le noter dans le rapport (ne pas en inventer sans le signaler).
- Les overlays (menus, dialogues) sont des copies `P · Overlay / …` ; la frame d'état `Proto / …` correspondante sert de **cible navigate-to** quand l'overlay n'est pas pertinent (ex. tri : la frame triée est la cible).
- Tous les flows sont en **clair**, 1440×900 (1366 pour `Default + outline`). Le web responsive (B13) n'est pas câblé.
