# Wiro *(working name)*

> Open-source collaborative workspace — Notion-style docs + Miro-style infinite canvas. Built in Rust. Self-hostable. MIT.

**Status:** pre-alpha · planning phase (BMAD).

- Desktop (Windows / macOS) + self-hosted web
- Docs ↔ canvas in one workspace, real-time collaboration
- Sovereign / enterprise deployment option
- Designed for African teams first

See [`docs/`](docs/) for product, research, UX and architecture documents.
