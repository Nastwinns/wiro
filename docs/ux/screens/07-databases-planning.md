# 07 — Databases & planning (UC3)

## S-07.1 Table view
Header: database title, view tabs (Tableau, Kanban, Chronologie, Calendrier, Liste, + vue), toolbar: Filtrer · Trier · Grouper · Propriétés · Rechercher · Nouveau. Grid: sticky first column, 32 px rows, inline edit, column resize, property type icons; footer calculations (count, sum, %). Virtualised (100k rows).

## S-07.2 Kanban
Columns by select/status property; cards show title + 2–3 chosen properties + assignee avatars; drag between columns (dnd-kit); WIP limit optional; "+ Nouveau" per column; collapsed columns.

## S-07.3 Timeline (Gantt-lite)
Rows = items (grouping optional), bars from start/end dates, drag to move/resize, dependencies (arrow), today line, zoom day/week/month/quarter. Also available as **canvas roadmap** (lanes on a board linked to DB items).

## S-07.4 Calendar
Month/week; items by date property; drag to reschedule; "Sans date" tray.

## S-07.5 Record page
Opens as side peek (default) or full page: properties block on top, then doc body; comments; relations as chips.

## S-07.6 Meeting notes
Template: Date, Participants (people), Agenda (checklist), Notes, **Décisions** (decision blocks with owner/date), **Actions** (each line → task in Tasks DB with assignee/due). Header actions: "Démarrer l'atelier" (opens linked board), "Envoyer le compte rendu" (export/share). Appears in Home "Pour moi" for assignees.
